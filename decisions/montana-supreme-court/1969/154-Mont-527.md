# State v. Porter

## Majority (PEE CUBIAM:)

PEE CUBIAM:
Defendant in this cause has filed a petition for a rehearing and the Court having considered the matters therein set forth.
Ordered that a rehearing be granted. The cause will be set upon the March Calendar and counsel for the State of Montana should file and serve its answer brief in response to the memorandum filed by defendant on or before February 25, 1970.
See 155 Mont., 466 P.2d 905.
